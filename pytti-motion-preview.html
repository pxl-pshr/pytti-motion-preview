Transform Expressions
Python, the way PyTTI evaluates it: t is seconds, with pi, sin, radians, ** and the rest of the math module, plus depth r R mu.
+x / +y shift the image right / up (the camera moves left / down); +z moves into the scene. Rotation x tilts up, y turns right, z rolls the image clockwise. PyTTI's lock_camera is on by default and cancels x/y moves and turns: set it to false to get this path.
Frame Settings
t = frame / FPS, so set FPS to the config's frames_per_second. r, R and mu are PyTTI's nearest, farthest and typical depth in pixels; they change with the image, so pick values to test with.
