PREVIEW
Real-time camera path visualizer for AI video

A browser-based tool for previewing PYTTI camera motion expressions before committing to a full render. Paste your translate/rotate expressions or a whole pytti preset, scrub the timeline, and see the 3D path and live camera view update instantly. No installation. No server. Open the file and go.

Launch Tool
01
Expression Engine
Expressions are read the way PyTTI reads them: Python, with t in seconds, pi, **, //, x if c else y and all of the math module. Mistakes are flagged with the frame PyTTI would fail on.
02
3D Path View
Watch the accumulated camera trajectory render live in a 3D observer scene. Gradient line from start to end, with tick marks and frustum at the current frame.
03
Camera View
Switch to first-person camera view to see exactly what the AI diffusion model's virtual camera sees at each frame of the animation.
04
Quaternion Engine
Rotation uses PYTTI's native [w, x, y, z] quaternion format, with PyTTI's own axis directions. Pitch, yaw and roll readouts update per frame, and a warning flags quaternions PyTTI won't normalize.
05
Path Analysis
Automatic loop detection, total path distance, and max radius from origin — quickly validate whether your motion will return to start.
06
PyTTI Config In / Out
Copy or save the motion as a pytti preset, or paste or drop one to load its expressions, FPS and frame count. A single HTML file: no build, no npm, no server.
Example Expressions
# PyTTI's default: circle a point ~1200 px ahead, pushing in every 10 s translate_x: '-1700*sin(radians(1.5))' translate_y: '0' translate_z_3d: '(50+10*t)*sin(t/10*pi)**2' rotate_3d: '[cos(radians(1.5)), 0, -sin(radians(1.5))/sqrt(2), sin(radians(1.5))/sqrt(2)]' # Dolly in while turning right 1° per frame translate_z_3d: '20' rotate_3d: '[cos(radians(0.5)), 0, sin(radians(0.5)), 0]' # Push in and pull out every 4 seconds translate_z_3d: '40*sin(2*pi*t/4)' rotate_3d: '[1, 0, 0, 0]'
// paste expressions or a whole preset straight from your pytti config
How To Use
01
Open the tool
Click "Launch Tool" above, or open pytti-motion-preview.html directly in your browser from disk.
02
Paste your expressions
Enter translate_x, translate_y, translate_z_3d and rotate_3d in the left panel, or paste or drop a pytti preset to load them. The path recomputes as you type (400ms debounce).
03
Scrub or play
Use the timeline slider or hit Play to animate. Set FPS to your config's frames_per_second: t is in seconds, so it changes the path.
04
Switch views
Toggle between PATH (3D observer) and CAM (first-person) to validate both the trajectory shape and the frame-by-frame camera perspective.
05
Confirm and render
When the path looks right, Copy YAML or save a .yaml preset for pytti. The path follows PyTTI's own transform math; render with lock_camera: false, since the default lock cancels x/y moves and turns.
